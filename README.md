# HyperUtil

Portal comparador de produtos focado em **impressão 3D** e **drones**. Stack: Next.js (App Router) + Tailwind CSS.

## Rotas

| Caminho | Função |
| --- | --- |
| `/` | Comparador / home |
| `/duelos` | Duelo lado a lado |
| `/recomendador` | Quiz de recomendação |
| `/noticias` | Feed editorial |
| `/admin` | Painel de administração |

## Desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
